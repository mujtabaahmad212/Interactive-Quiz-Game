# Interactive Quiz Game

An interactive quiz game where users can test their knowledge on various topics. The game features multiple questions, scoring, and immediate feedback for each answer.

## Features

- Multiple-choice questions
- Real-time scoring and feedback
- User-friendly interface
- Responsive design

## Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/mujtabaahmad212/Interactive-Quiz-Game.git
    cd Interactive-Quiz-Game
    ```
2. Open `index.html` in your web browser to play the game.

## Tech Stack

- JavaScript
- HTML5
- CSS3

## Usage

- Start the quiz and select answers for each question.
- View your score and feedback after completing the quiz.
